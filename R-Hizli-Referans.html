R ve RStudio Kurulum Rehberi

IST2083 — çalışma ortamının kurulumu

Yazar

Prof. Dr. Hakan Mehmetcik

Yayınlanma Tarihi

r Sys.Date()

Bu Belge Nedir?

Bu, her hafta büyüyen bir başvuru belgesidir. Yeni bir ders notunda yeni bir R fonksiyonu veya sözdizimi geçtiğinde, buraya kısa bir girişle eklenir. Amaç: 9. oturumda bir sözdiziminin nasıl yazıldığını unuttuğunuzda, o oturumun ders notunu baştan açmak yerine buraya bakıp tek satırda hatırlamanız.

Önemli

Bu belgedeki kod örnekleri çalıştırılmaz (render sırasında işletilmez) — bunlar birbirinden bağımsız, kısa hatırlatma parçalarıdır, tam bir script değildir. Çalışan, açıklamalı örnekler için ilgili oturumun ders notuna bakınız; her girişte hangi oturumda işlendiği belirtilmiştir.

Her giriş şu düzendedir: ne işe yarar, kısa örnek, hangi oturumda tanıtıldı.

Operatörler

Aritmetik

5 + 3    # toplama
5 - 3    # çıkarma
5 * 3    # çarpma
5 / 3    # bölme
2 ^ 3    # üs alma
5 %% 3   # modülüs (kalan)
5 %/% 3  # tam bölme

1. oturum

Karşılaştırma

5 == 3   # eşit mi?
5 != 3   # eşit değil mi?
5 > 3; 5 < 3
5 >= 3; 5 <= 3

1. oturum

Mantıksal

TRUE & FALSE    # VE (vektörel — tüm elemanları karşılaştırır)
TRUE && FALSE   # VE (yalnızca ilk elemanı karşılaştırır)
TRUE | FALSE    # VEYA (vektörel)
TRUE || FALSE   # VEYA (yalnızca ilk eleman)
!TRUE           # DEĞİL

1. oturum

Diğer

1:10               # ardışık sayı dizisi (kolon operatörü)
seq(1, 10, by = 2) # dizi oluşturma, adım belirterek
rep(1:3, times = 3) # tekrar
3 %in% c(1, 2, 3)  # üyelik sorgusu — sağdaki vektörde var mı?

1. oturum

Değişkenler ve Atama

x <- 10   # standart atama (tercih edilen)
y = 20    # de çalışır, ama R camiasında <- yaygın

1. oturum

R’da temel veri türleri: sayısal (numeric), karakter (character), mantıksal (logical). Bir değişkenin türünü öğrenmek için:

class(x)

2. oturum

Veri Yapıları

Vektör

Aynı türden elemanların sıralı listesi.

v <- c(1, 2, 3, 4, 5)     # sayısal vektör
k <- c("a", "b", "c")     # karakter vektör
m <- c(TRUE, FALSE, TRUE) # mantıksal vektör

v[2]          # 2. elemana eriş
v[2] <- 10    # 2. elemanı güncelle
sum(v)        # elemanların toplamı

2. oturum

Liste

Farklı türden elemanları bir arada tutar.

l <- list(sayi = 5, mesaj = "Merhaba", bayrak = TRUE)

l$sayi          # elemana isimle eriş
l$sayi <- 10    # güncelle
l$yeni <- "ek"  # yeni eleman ekle
l$yeni <- NULL  # elemanı sil

2. oturum

Matris

Aynı türden, satır-sütun düzeninde iki boyutlu veri.

mat <- matrix(1:6, nrow = 2, ncol = 3)

mat[1, 2]   # 1. satır, 2. sütun
mat[2, ]    # 2. satırın tamamı
mat[, 3]    # 3. sütunun tamamı

mat1 %*% mat2   # matris çarpımı (eleman eleman değil!)

2. oturum

Veri Çerçevesi (Data Frame)

Farklı türden sütunları olan tablo — en çok kullanacağınız yapı.

df <- data.frame(
  sayi = c(1, 2, 3),
  harf = c("a", "b", "c")
)

df[1, 2]       # 1. satır, 2. sütun
df$sayi        # bir sütunun tamamı (isimle)
df$sayi[2]     # bir sütunun belirli bir elemanı

df$yeni <- c(10, 20, 30)          # yeni sütun ekle
df <- rbind(df, list(4, "d", 40)) # yeni satır ekle

2. oturum

Faktör (kategorik değişken)

Sonlu bir kategori kümesi; sosyal bilimde en sık kullanılan tür.

rejim <- factor(c("Demokrasi", "Otokrasi", "Melez", "Demokrasi"))

levels(rejim)      # kategorilerin kümesi (tekrarsız)
table(rejim)       # frekans sayımı
nlevels(rejim)     # kaç kategori var

# Sıralı faktör: hiyerarşiyi siz tanımlarsınız
egitim <- factor(c("Lisans", "Lise", "Doktora"),
                 levels  = c("Lise", "Lisans", "Yüksek Lisans", "Doktora"),
                 ordered = TRUE)
egitim[1] > egitim[2]              # TRUE

# TUZAK: faktörü sayıya çevirirken
as.numeric(faktor)                 # seviye NUMARASI — genellikle yanlış
as.numeric(as.character(faktor))   # gerçek değer — doğrusu

2. oturum

Tür zorlaması ve eksik veri

class(c(1, 2, "üç"))     # "character" — tek metin tüm vektörü çevirir
class(c(1, 2, TRUE))     # "numeric"   — TRUE, 1 olarak okunur
sum(c(TRUE, TRUE, FALSE))# 2           — koşulu kaç eleman sağlıyor
sum(x > 60)              # aynı mantık: kaç eleman 60'tan büyük

# Hiyerarşi: logical -> integer -> double -> character

5 + NA                   # NA — bilinmeyene ekleme yine bilinmez
NA == NA                 # NA — TRUE değil!
is.na(x)                 # eksik değerleri BÖYLE ararsınız
sum(is.na(x))            # kaç eksik var
mean(x, na.rm = TRUE)    # eksikleri dışlayarak hesapla

2. oturum

Mantıksal indeksleme

Köşeli parantezin içine konum numarası yerine bir koşul yazarsanız, R önce koşulu her eleman için sınayıp bir TRUE/FALSE maskesi üretir, sonra TRUE olan konumları tutar.

v <- c(4, 7, 2, 9, 5)

v > 5                  # maske: FALSE TRUE FALSE TRUE FALSE
v[v > 5]               # 7 9
v[v > 3 & v < 9]       # 4 7 5      (VE)
v[v > 8 | v < 3]       # 2 9        (VEYA)
v[!(v == 2)]           # 4 7 9 5    (DEĞİL)

df[df$sayi > 1, ]      # koşulu sağlayan SATIRLAR
df[df$sayi > 1, "harf"] # koşulu sağlayan satırların bir sütunu

Virgül kritiktir: öncesi satırları, sonrası sütunları seçer. Eşitlik sınaması daima == iledir; = atama içindir.

1. oturum

Bu kılavuz üç şeyi anlatır: GitHub hesabı açmayı, ders deposunu bilgisayarınıza indirmeyi ve her hafta yeni materyali almayı.

Üçüncüsü en önemlisi. Depoyu bir kez indirip bırakırsanız 3. haftadan sonra elinizdeki materyal eskir.

1. GitHub hesabı açma

  1. https://github.com/ adresine gidin, sağ üstten Sign up’a tıklayın.
  2. E-posta, kullanıcı adı ve şifre girin.
  3. Gelen onay e-postasındaki bağlantıya tıklayarak hesabı doğrulayın.

Hangi e-posta? Herhangi bir e-posta adresiyle kayıt olabilirsiniz; .edu.tr zorunlu değildir. Ancak öğrenci e-postanızı hesabınıza eklerseniz GitHub Student Developer Pack başvurusu yapabilir, Codespaces için ek ücretsiz kullanım hakkı ve başka araçlara erişim kazanabilirsiniz: https://education.github.com/pack

Öğrenci e-postanızı sonradan da ekleyebilirsiniz: Settings → Emails → Add email address.

2. Depoyu bilgisayarınıza indirme

Bu adımdan önce R, RStudio ve Git kurulu olmalıdır. Kurulum için R_RStudio_Kurulum_Rehberi dosyasına bakınız.

  1. RStudio’yu açın.

  2. File → New Project → Version Control → Git

    Version Control seçeneğini göremiyorsanız Git kurulu değildir veya RStudio Git’i bulamamıştır. Kurulum rehberindeki Git bölümüne dönün.

  3. Repository URL alanına şunu yapıştırın:

    https://github.com/Proximalist/IST2083.git

  4. Project directory name: IST2083 olarak bırakın.

  5. Create project as subdirectory of: derslerinizi tuttuğunuz klasörü seçin. Türkçe karakter ve boşluk içermeyen bir yol tercih edin (Belgeler/Dersler gibi).

  6. Create Project’e tıklayın.

İndirme bitince RStudio projeyi açar. Sağ altta dosya listesini, sağ üstte Git sekmesini görmelisiniz.

Doğrulama

Console’a şunu yazın:

library(here)
here()
file.exists(here("data", "example_data.csv"))

TRUE görüyorsanız her şey yolundadır.

3. Her hafta güncel materyali alma

Ders materyali her hafta güncellenir. Yeni materyali almak için:

RStudio’da: Git sekmesi → mavi aşağı ok (Pull) düğmesi.

Veya Console’da (Terminal sekmesi):

git pull

Bunu her dersten önce yapın. Yeni haftanın klasörü, düzeltilmiş kodlar ve cevap anahtarları bu şekilde gelir.

“Pull çalışmıyor, hata veriyor”

En sık karşılaşılan iki durum:

Durum A — ders dosyalarını değiştirdiniz ve pull reddedildi. Hata şuna benzer: “Your local changes would be overwritten by merge.”

Ders dosyalarının üzerine yazmak yerine kopyasını alıp çalışın. Değişiklikleri atmak isterseniz:

git stash
git pull

git stash, değişikliklerinizi kenara koyar; geri almak isterseniz git stash pop yazın.

Durum B — kendi dosyalarınız var ama takip edilmiyor. Alıştırma çözümlerinizi benim_calismalarim/ gibi kendi klasörünüzde tutarsanız pull hiç sorun çıkarmaz. Bu klasörü depoya göndermeniz gerekmez.

Önemli: Bu depoya push yapmanız beklenmiyor ve yetkiniz yok. Depo tek yönlü çalışır: biz yayımlarız, siz pull ile alırsınız.

4. Alternatif: GitHub Codespaces (kurulum istemeyenler için)

Bilgisayarınıza hiçbir şey kurmadan, tarayıcıda çalışabilirsiniz.

  1. https://github.com/Proximalist/IST2083 adresine gidin.
  2. Yeşil Code düğmesi → Codespaces sekmesi → Create codespace on main.
  3. Tarayıcıda bir editör açılır; R ve gerekli paketler hazır gelir.

Bilmeniz gerekenler:

  • Codespaces ücretsiz kotayla çalışır (hesap türüne göre aylık belirli bir süre). Kullanmadığınızda Stop codespace ile durdurun, kota tükenmesin.
  • Ders anlatımı RStudio arayüzü üzerinden yapılacaktır; Codespaces’te ekran farklı görünür.
  • Codespaces içinde yaptığınız değişiklikler o codespace’te kalır, bilgisayarınıza inmez.

Uzun vadede yerel RStudio kurulumu tavsiye edilir; Codespaces kurulum sorununu çözemediğiniz haftalarda iyi bir yedektir.

5. Depoyu indirmenin en basit yolu (Git olmadan)

Git ile uğraşmak istemiyorsanız:

  1. https://github.com/Proximalist/IST2083 → yeşil Code düğmesi → Download ZIP.
  2. ZIP’i açın, içindeki IST2083.Rproj dosyasına çift tıklayın.

Dezavantajı: Her hafta yeniden indirmeniz gerekir ve eski klasörle karıştırma riski vardır. Git yolunu öğrenmek ilk hafta biraz zaman alır ama dönem boyunca zaman kazandırır.

Kontrol listesi (2 dakikalık özet)

Birkaç ek hata senaryosu

“Permission denied (publickey)” SSH adresi yerine bu kılavuzdaki HTTPS URL’ini kullandığınızdan emin olun: https://github.com/Proximalist/IST2083.git

“fatal: not a git repository” Komutu proje klasörünün içinde çalıştırın. pwd (macOS/Linux) veya cd (Windows, argümansız) ile hangi klasörde olduğunuzu kontrol edin.

“already exists and is not an empty directory” Aynı isimli bir klasör zaten var. Klonlarken farklı bir Project directory name seçin veya eski klasörü silin/taşıyın.

Sorun mu var?

Depoda Issues sekmesini açıp yeni bir issue oluşturun. Şunları yazın:

  • Ne yapmaya çalıştığınız
  • Hata mesajının tamamı (ekran görüntüsü değil, metin olarak)
  • İşletim sisteminiz

Aynı sorunu yaşayan arkadaşlarınız da cevabı görecektir.

İyi çalışmalar!

Dört adım var ve sırası önemlidir: önce R, sonra RStudio, sonra Git, en son paketler. Toplam süre 20–30 dakika (indirme hızınıza bağlı).

Neden Git de gerekiyor? Ders materyalini her hafta güncel almak için. Git kurulu değilse RStudio’da o seçenek hiç görünmez.

1. R’ı kurun

R, hesaplamayı yapan motordur. Doğrudan kullanmayacaksınız ama olmadan RStudio çalışmaz.

https://cran.r-project.org/

  • Windows: Download R for Windows → base → Download R x.x.x for Windows → indirilen .exe dosyasını çalıştırın, varsayılan ayarlarla ilerleyin.
  • macOS: Download R for macOS → işlemcinize uygun .pkg dosyasını seçin. Apple Silicon (M1/M2/M3/M4) için arm64 yazan sürümü, eski Intel Mac’ler için düz sürümü indirin. Emin değilseniz: Elma menüsü → Bu Mac Hakkında → “Çip” satırında “Apple” yazıyorsa arm64’tür.
  • Linux: Dağıtımınıza göre CRAN sayfasındaki talimatları izleyin.

2. RStudio’yu kurun

RStudio, R ile çalıştığınız arayüzdür. (RStudio’yu geliştiren şirket 2022’de adını Posit olarak değiştirdi; indirme sayfası posit.co altındadır. Ürünün adı hâlâ RStudio’dur.)

https://posit.co/download/rstudio-desktop/

RStudio Desktop — Free sürümünü indirin. Sayfa işletim sisteminizi otomatik tanır. Kurulumu varsayılan ayarlarla tamamlayın.

Açtığınızda dört bölmeli bir pencere görmelisiniz. Sol alttaki Console bölmesi komut yazdığınız yerdir.

3. Git’i kurun

macOS

Terminal’i açın (Spotlight → “Terminal”) ve şunu yazın:

git --version

Sürüm numarası çıkıyorsa Git zaten kuruludur, 4. adıma geçin. Çıkmıyorsa bir kurulum penceresi açılır; Install deyin. Alternatif olarak:

xcode-select --install

Windows

https://git-scm.com/download/win adresinden indirin. Kurulum sihirbazında tüm varsayılan ayarları değiştirmeden ilerleyin.

Linux

sudo apt install git        # Debian/Ubuntu
sudo dnf install git        # Fedora

Kurulumdan sonra: kimlik bilgisi

Terminal’de (veya RStudio’nun Terminal sekmesinde) bir kez çalıştırın:

git config --global user.name "Adınız Soyadınız"
git config --global user.email "eposta@adresiniz"

RStudio Git’i görüyor mu?

RStudio’yu kapatıp yeniden açın (Git’i kurduktan sonra bu şart), sonra:

Tools → Global Options → Git/SVN → Git executable alanında bir yol yazıyor olmalı. Boşsa Browse ile Git’in konumunu gösterin (Windows’ta genellikle C:/Program Files/Git/bin/git.exe).

4. Paketleri kurun

R’ın kendisi çıplak gelir; dersimizin araçları paketlerle gelir. RStudio’nun Console bölmesine aşağıdakini yapıştırıp Enter’a basın:

install.packages(c(
  "tidyverse",   # dplyr, ggplot2, tidyr, readr — dersin omurgası
  "here",        # dosya yollarını taşınabilir kılar
  "readxl",      # Excel dosyaları
  "haven",       # Stata/SPSS dosyaları
  "janitor",     # veri temizliği
  "knitr",       # rapor üretimi
  "rmarkdown",
  "gapminder"    # ders boyunca kullanacağımız veri seti (1. haftadan itibaren)
))

Bu birkaç dakika sürer ve çok satır çıktı üretir; normaldir. Sarı renkli uyarılar (Warning) sorun değildir; kırmızı Error satırları sorundur.

Windows’ta soru gelirse: “Do you want to install from sources the packages which need compilation?” → no yazıp Enter’a basın.

Dersin ilerleyen haftalarında birkaç paket daha eklenecektir; o haftanın dosyasının başında hangi paketin gerektiği yazılıdır.

Quarto

Ders notları Quarto ile yazılmıştır. Güncel RStudio sürümleri Quarto’yu içinde getirir. Ayrıca kurmak isterseniz: https://quarto.org/docs/download/

5. Kurulumu doğrulayın

Console’a sırayla yazın:

print("Merhaba, R ve RStudio'ya hoş geldiniz!")

library(tidyverse)
library(here)

R.version.string

Üçü de hatasız çalışıyorsa kurulum tamamdır.

Grafik testi:

ggplot(mtcars, aes(x = wt, y = mpg)) +
  geom_point() +
  labs(x = "Ağırlık", y = "Mil/Galon")

Sağ alt bölmede bir dağılım grafiği görmelisiniz.

6. Sonraki adım

GitHub_Kullanım_Kılavuzu dosyasına geçin ve ders deposunu bilgisayarınıza indirin.

Sık karşılaşılan sorunlar

“there is no package called ‘tidyverse’” Paket kurulmamış veya kurulum hata vermiş. install.packages("tidyverse") komutunu tekrar çalıştırın ve çıktıda kırmızı Error satırı arayın.

Türkçe karakterler bozuk görünüyor (Windows) Tools → Global Options → Code → Saving → Default text encoding’i UTF-8 yapın.

Kurulum “Kütüphane yazılabilir değil” hatası veriyor Kullanıcı adınızda Türkçe karakter varsa R kütüphane klasörünü oluşturamayabilir. RStudio’yu yönetici olarak çalıştırmayı deneyin; sorun sürerse Issues’ta bildirin.

RStudio açılıyor ama Console’da hiçbir şey olmuyor R kurulmadan RStudio kurulmuş olabilir. R’ı kurup RStudio’yu yeniden başlatın.

Çözemediğiniz sorun için depodaki Issues sekmesini kullanın; hata mesajının tamamını ve işletim sisteminizi yazın.

İyi çalışmalar!
